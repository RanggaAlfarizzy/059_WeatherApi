## Deskripsi
Project ini menggunakan API MapTiler untuk mendapatkan data lokasi berdasarkan kota yang dimasukkan.

Data yang ditampilkan:
- Lokasi
- Negara
- Provinsi
- Kecamatan
- Longitude
- Latitude

## API Endpoint

GET:

`/api/lokasi/:kota`

Contoh:

`http://localhost:3000/api/lokasi/bandung`
